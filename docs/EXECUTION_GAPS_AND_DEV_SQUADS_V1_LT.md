# Execution Gaps and Dev Squads v1 LT

Tikslas: aiskiai ivardinti, ko dar truksta, kad AI Business Factory greiciau judetu i pajamas, produktus ir autonomini vykdyma.

## Didziausi tarpai

1. Coding Factory truksta kaip atskiro sluoksnio.
2. Nera pilnai uzdaryto agent registry su decision rights ir kill criteria.
3. Nera pilno task queue worker runtime su dashboardu.
4. Nera revenue dashboardo: lead, reply, demo, paid pilot, delivery, maintenance.
5. Nera pilno delivery playbook kiekvienam produktui.
6. Nera pakankamai automatiniu testu.
7. Nera pilnos API integraciju strategijos.
8. Nera customer research ir buyer interview ciklo.
9. Nera pakankamai conversion design iteraciju.
10. Nera pilnai uzdaryto video and content production pipeline.
11. Nera security and access playbook.
12. Nera data quality and observability dashboardo.
13. Nera full weekly performance review visu agentu ir vadovu.

## Ar truksta koduotoju

Taip. Truksta ne siaip daug koduotoju, o organizuotu dev squad'u.

Reikia 5 dev squad'u:

1. Core Platform Squad.
2. Product UI Squad.
3. Data and Pricing Squad.
4. Automation and Integration Squad.
5. QA DevOps and Reliability Squad.

## Minimalus dev stack dabar

1. Tech Lead.
2. Backend Developer.
3. Frontend Developer.
4. Full Stack Developer.
5. DevOps Engineer.
6. QA Automation Engineer.
7. Data Engineer.
8. Integration Engineer.
9. AI Orchestration Engineer.
10. Security Engineer.

## Agentu-dev roliu modelis

Kiekvienas dev agentas privalo tureti:
- ownership area;
- input contract;
- output contract;
- test requirement;
- done proof;
- review owner;
- rollback notes;
- money or automation reason.

## Ko nedaryti

- Nekurti nauju agentu be output kriteriju.
- Nekurti graziu dokumentu be vykdomo tasko.
- Nekurti funkciju be revenue arba automation reason.
- Nekurti produktu be product gate.
- Nepaleisti release be QA ir rollback.

## Pirma savaite

4. Sukurti revenue dashboard MVP.
5. Sukurti daily worker report.
6. Sutvarkyti landing conversion first pass.
7. Sukurti 20 leadu sarasa ir outreach pack.
8. Sukurti 10 competitor profiles.
9. Sukurti delivery checklist.
10. Sukurti QA smoke test checklist.

## Done criteria

Sitas sluoksnis laikomas aktyviu, kai:
- yra dev squad registry;
- kiekvienas squad turi owneri;
- yra aktyvus task queue;
- kasdien vyksta bent vienas revenue arba product improvement;
- kiekvienas pakeitimas turi test arba review;
- kas savaite matomas output report.
