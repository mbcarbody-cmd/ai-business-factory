# Owner Input and Project Priorities v1 LT

Tikslas: uzrakinti savininko krypti ir paversti ja execution planu.

## Savininko ivestis

1. Pagrindines kryptys:
   - RepoBuy / RepoSell: viena svetaine pardavejams, kita pirkejams, kaip naudotu autodaliu marketplace ir seller OS.
   - Reklamos agentura: rupinasi visu produktu promotion ir lead generation.
   - AI media fabrikas: kontentas ziurovams, short content, social content, audience building.
   - Pazinciu portalas: atskiras velesnis produktas.

2. Reklama yra kritine. Be reklamos ir promotion, Repo projektai neveiks.

3. Kol nera produkto, kaina nera galutine.

4. Auditorija priklauso nuo pirmo veikiancio produkto.

5. Pirma rinka: Europa.

6. Kol nera produkto, domenas ir pastas gali buti sprendziami veliau.

7. Mokėjimas pradziai gali buti per saskaita / banko pavedima.

8. Social kanalai: visi, kurie duoda pelna ir nekelia per dideles rizikos.

## Strateginis sprendimas

Pagrindinis flagship projektas: RepoBuy / RepoSell.

Pirmas pajamu variklis: Reklamos agentura + AI media fabrikas, nes jie gali generuoti leadus, testuoti auditorijas ir padeti parduoti dar pries pilnai baigta marketplace.

Pirmas techninis MVP: RepoSell seller OS, nes pardavejai turi aiskia problema: prekiu valdymas, listingai, kainodara, sandelis, reklama ir uzsakymai.

RepoBuy pirkeju portalas eina po to, kai yra bent minimalus seller supply ir listings.

Pazinciu portalas: backlog, nes jam reikia atskiros legal, moderation, safety, anti-abuse ir network-effects strategijos.

## Prioritetu tvarka

1. RepoSell seller OS MVP.
2. Growth agency revenue engine.
3. AI media factory content engine.
4. RepoBuy buyer marketplace MVP.
5. Pazinciu portalas discovery stage.

## Pirmas money path

Kol marketplace dar statomas, pirmas parduodamas dalykas gali buti ne pilnas marketplace, o:

- seller listing automation setup;
- seller inventory workflow setup;
- pricing assistance setup;
- content and promotion package for sellers;
- lead generation package for auto parts sellers;
- marketplace waitlist and early seller onboarding.

## Ko reikia is savininko minimaliai dabar

1. Patvirtinti, kad pirmas MVP yra RepoSell seller OS.
2. Pasakyti, ar pirmas segmentas yra naudotu autodaliu pardavejai Europoje.
3. Pateikti arba patvirtinti pirma imones atsiskaitymo kelia, kai atsiras pirmas klientas.
4. Pasakyti, ar galima kurti laikina landing be galutinio domeno.
5. Pasakyti, kokias social paskyras pirmas sukurti: Facebook, Instagram, TikTok, YouTube, LinkedIn.
6. Parinkti offsite backup vieta arba leisti sistemai pradeti nuo GitHub + server backup + veliau cloud storage.
7. Patvirtinti, kad pazinciu portalas lieka veliau, ne pirmas build.
