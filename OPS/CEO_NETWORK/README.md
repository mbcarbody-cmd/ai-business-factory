# CEO Network

Goal: build a network of specialist business leaders and agents that can research many directions while builders stay focused on the best approved opportunities.

## Main principle

Many leaders can research. Few products should be built at the same time.

## Structure

- Master CEO: chooses the global priority.
- Vertical CEO: owns one business direction.
- Analyst: studies demand and alternatives.
- Product: defines MVP and workflow.
- Builder: creates real files and demos.
- Reviewer: checks gaps and usability.
- Growth: prepares page, content and lead material.
- Ops: prepares delivery and support.
- Finance: checks cost and package logic.
- Auditor: records what changed and next step.

## Build gate

A direction can move from research to build only when it has:

- clear user
- clear problem
- demo path
- package value
- target list
- delivery path
- main CEO approval
