# Competitor Findings Memory

Purpose: keep competitor discoveries reusable across strategy, pricing, landing pages and product gates.

## Entry format

- Date
- Competitor
- Segment
- Offer
- Price
- CTA
- Strength
- Weakness
- Gap we can use
- Action created
