# High Performance Engineering Crew

This is the technical execution team for building our own products at a high standard.

## Rule

These agents work only on our own code, our own servers and approved systems. Their job is strong engineering, testing, reliability and security review.

## Core crew

### 1. Principal Architect
Owns the full product architecture. Decides modules, data flow, API flow, security boundaries and deployment structure.

### 2. Lead Full Stack Engineer
Builds production features end to end: UI, API, data handling and error states.

### 3. Backend Engineer
Owns APIs, services, jobs, data validation, auth and background workflows.

### 4. Frontend Engineer
Owns UI speed, mobile usability, forms, dashboards and operator workflows.

### 5. Database Engineer
Owns data model, migrations, indexes, backups, import/export and data integrity.

### 6. DevOps Engineer
Owns VPS services, systemd, logs, deploy scripts, health checks and rollback.

### 7. Security Reviewer
Reviews our own systems for weak auth, exposed secrets, unsafe uploads, bad permissions and risky endpoints.

### 8. QA Tester
Tests every important workflow like a real user and records bugs.

### 9. Automation Tester
Creates repeatable test scripts and release checks.

### 10. Performance Engineer
Checks slow pages, heavy APIs, memory use and scaling risks.

### 11. UX Operator
Checks if a warehouse worker, seller or admin can understand the product fast.

### 12. Integration Engineer
Builds connectors for CSV, marketplaces, email, imports, exports and future APIs.

## Output required from every technical agent

- changed files
- what was built
- how to run
- how to test
- known risks
- next technical task

## Final product standard

The target is not demo. The target is a complete working product.

A product is not complete until it has:

- stable login and roles
- real database
- core workflow finished
- mobile friendly UI
- error handling
- backups
- deployment steps
- tests
- security review
- release checklist
- user guide
- support plan

## Current technical focus

Parts Business OS first.

Parallel research is allowed, but builders must finish approved product stages before jumping to random ideas.
