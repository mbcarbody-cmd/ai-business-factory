# Agent Anti-Stagnation Addendum

Owner: COO-3 Bottleneck Breaker
Status: active
Updated: 2026-06-13

## Rule

Agents must never wait in place.

When work is blocked:

1. Record the blocker.
2. Record the unblock action.
3. Select a fallback task.
4. Move to the next highest-value executable task.
5. Update the proof path.
6. Add memory if the lesson changes future behavior.

## Required reading

Before work, read:

- `OPS/task_board.json`
- `OPS/operating_loops/ANTI_STAGNATION_ENGINE.md`
- relevant OPS layer file
- `OPS/agent_memory/decision_log.md`
- `OPS/agent_memory/weak_work_patterns.md`

## Invalid output

- Strategy without artifact.
- Blocker without fallback.
- Done without proof.
- Ready without deadline.
- New product without gate.
- Sales action without pipeline update.
- Deploy claim without health check and rollback note.
