# Content Funnel Patterns

Owner: CI-4 Content Intelligence Analyst  
Cadence: daily capture, weekly conversion review  
Status: active

## Purpose

Collect social posts, ads, reels, landing hooks and creator funnels that sell small SaaS, AI automation, seller tools or marketplace products. Do not copy them. Deconstruct the mechanism, convert it into our own offers, and create product, content or revenue tasks.

Every useful pattern must answer:

1. Who is the exact audience?
2. What pain or contrast is used?
3. What simple dream outcome is promised?
4. What visual pattern makes the message instantly understandable?
5. What CTA sends the buyer to the next step?
6. Which internal offer, page, video or product task should change because of it?

## Pattern 2026-06-14 — Micro-SaaS pseudo-code contrast post

Source type: user-provided screenshot from social feed.  
Source status: user_provided; original public page not independently verified in repo.  
Segment: micro-SaaS / pet-project / indie hacker content funnel.

### What works

Audience: developers and IT managers who want a small side project while keeping their job.

Pain or contrast: job hopping for a higher salary creates stress, interviews and another ceiling; micro-SaaS creates owner upside.

Dream outcome: small recurring revenue, e.g. first 1000 USD MRR, 10 hours/week, no salary ceiling.

Visual pattern: VS Code / Python pseudo-code. It makes the business idea feel native to the target audience.

CTA: one clear button to read/join the Telegram channel.

### Reusable formula

```
Why [small owned product] beats [linear work path]?

linear_path():
    stress = high
    upside = capped
    ownership = false
    return "same ceiling"

owned_system():
    first_revenue = small_but_real
    hours_per_week = low
    upside = uncapped
    ownership = true
    return "your rules, recurring revenue"

CTA: join / request audit / see demo / get checklist
```

## Pattern 2026-06-14 — AI tool stack listicle ad

Source type: user-provided screenshot from Facebook sponsored feed.  
Source status: user_provided; original ad and sponsor claim not independently verified in repo.  
Segment: AI course / AI certificate / beginner AI adoption funnel.

### What works

Audience: beginners, employees, freelancers, managers and creators who feel behind on AI and want a simple path to become more capable.

Pain or contrast: the world has too many AI tools and the buyer does not know what to learn first; the ad reframes the chaos as a simple tool stack that can make the person "unstoppable".

Dream outcome: learn the key AI tool categories, feel modern and competent, get a certificate/training path.

Visual pattern: large bold headline plus long categorized-looking bullet list. The list creates perceived completeness and makes the buyer think the course saves research time.

CTA: Start Now / Learn more.

### Reusable formula

```
[Category] tools that make you [desired identity]

- Tool 1 — simple role
- Tool 2 — simple role
- Tool 3 — simple role
...

Learn to use the whole stack -> [offer / checklist / certificate / audit]
```

### Why this matters for our system

This pattern sells by reducing confusion. It does not need deep product proof in the ad; it wins the click by saying: "Here is the map of the AI world, and we can guide you through it." Our version should not sell a generic course. It should sell an operational stack connected to a concrete result: seller OS, pricing workflow, lead workflow, content pack or 72h automation pilot.

## Guardrails

- Do not copy exact creative assets, names, or protected brand materials.
- Use patterns and mechanisms only.
- Do not claim results that are not proven.
- Every CTA must map to a real offer, demo, waitlist, audit or checklist.
- If a task is blocked by missing source verification, create a fallback task using the pattern with user-provided status only.
