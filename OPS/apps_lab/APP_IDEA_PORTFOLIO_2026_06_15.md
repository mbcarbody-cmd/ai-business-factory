## First 3 MVPs

### MVP-1: AI Date Planner

Landing page promise: Tell us your city, mood, budget and free time. Get 3 low-pressure date plans with place, activity, opener and safety notes.

User flow:
1. User fills short form.
2. AI creates 3 plans.
3. User picks one.
4. System asks for feedback.

Monetization:
- free first plan;
- 3-5 EUR for plan pack;
- 9-19 EUR monthly;
- later venue/event partnerships.

Data sources:
- public event pages;
- public venue pages;
- maps/business public pages;
- user-submitted preferences.

### MVP-2: AI Wingman

Landing page promise: Paste a message or situation. Get 3 replies: normal, playful and direct.

User flow:
1. User pastes message or context.
2. AI asks one clarifying question only if needed.
3. AI returns 3 reply styles.
4. User rates which one feels natural.

Monetization:
- free 3 replies/day;
- 4.99-9.99 EUR monthly;
- premium profile/help packs.

Data sources:
- user-submitted text only;
- no scraping private chats;
- no automated sending.

### MVP-3: NoSwipe curated intro experiment

Landing page promise: No endless swiping. Fill one honest form and get one curated intro or activity match per week.

User flow:
1. User fills profile form.
2. AI/human review matches by values, city, availability and interests.
3. First test goal is 10 good intro attempts.
4. After each intro, both sides give feedback.

Monetization:
- free waitlist;
- 10-20 EUR curated intro;
- paid small events;
- later subscription only if intros work.

Data sources:
- user-submitted form data;
- public event/activity sources;
- no private profile scraping.

## Browser agent rule

Browser agents may collect only public data with source_url, collected_at, allowed_use note and confidence. No private profiles, no fake accounts, no captcha bypass, no platform-rule bypass, no bulk messaging.

## Stop rule

Do not build a full app until one MVP gets a real signal: waitlist signups, replies, paid test, or 10 useful intro/date-plan feedback records.
