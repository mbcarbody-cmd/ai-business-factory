# AI Wingman Mini Prototype Spec

Date: 2026-06-15
Owner: AI Workflow Engineer + Product Marketing
Status: draft

## Promise

Paste a message or dating situation. Get 3 replies that sound human: normal, playful and direct.

## User flow

1. User pastes incoming message or describes situation.
2. User selects tone: normal, playful, direct, respectful, funny.
3. System returns 3 reply options.
4. User chooses one or asks for softer/stronger version.
5. User rates result.

## Safety and trust rules

- no automated sending;
- no impersonation;
- no manipulative pressure;
- no private scraping;
- user controls final message.

## Monetization test

- 3 free replies daily;
- paid pack for more replies;
- profile/bio helper upsell.

## Validation metric

At least 20 test users paste a message and choose one generated reply.
