# Fifth Gear Execution Mode LT

Date: 2026-06-13
Owner: CEO / Master Agent + COO-1 Execution Architect
Status: active

## Tikslas

Visi projektai turi judeti be laukimo. Kiekvienas aktyvus darbas privalo tureti owner, next action, output path ir proof.

## Taisykles

1. Jei darbas uzblokuotas, uzrasyti blocker ir pereiti prie kito naudingo veiksmo.
2. Kiekvienas agentas turi palikti konkretu outputa, ne tik plana.
3. Kiekvienas produktas turi judeti link demo, naudotojo vertes arba patikrinto poreikio.
4. Kiekvienas naujas produktas vertinamas pagal problemos stipruma, proof greiti, rizika, nauda ir pakartotini panaudojima.
5. Nera proof, nera done.

## Aktyvios kryptys

- Product proof: demo, UI, prototipai, testai.
- Customer discovery: realios problemos, segmentai, pasiulymai.
- Data quality: saltiniai, provenance, confidence.
- Creative: reklamu ir turinio variantai.
- Marketplace: daliu workflow, lokacijos, kainodaros pagalba, listing draft.
- Internal tools: cockpit, crawler, app skeleton, task board.

## Darbo ciklas

Kiekvienas ciklas turi pagaminti bent viena is siu rezultatu:

- demo pakeitima;
- verified source;
- product screen;
- customer segment note;
- QA bug;
- creative asset;
- data row;
- prototype file;
- next action handoff.

## No idle rule

Kai nera tiesiogines uzduoties, agentas renkasi auksciausios vertes darba is P0 saraso. Kai P0 blokuotas, renkasi P1 darba, kuris greiciausiai sukuria proof.

## Done definition

Mode veikia kai kasdien juda bent trys kryptys ir kiekvienas judesys turi output path.
