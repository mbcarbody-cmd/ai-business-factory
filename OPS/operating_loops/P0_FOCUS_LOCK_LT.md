## Purpose

Stop the system from spreading into too many unknown projects while the first lightweight app and revenue loop are not yet working.

## Current focus

`product brief -> hooks -> posts -> video scripts -> landing hero -> DM -> export -> content sprint offer -> first paid sprint proof`

## Focus rules

1. No new unrelated product build starts while Content Hook Factory is not sell-ready.
2. AI Pilot OS is rejected/parked.
3. Parts Seller OS remains parked as a later/heavier product.
4. New ideas may be captured only as backlog, not active P0 build.
5. Active build capacity goes first to:
   - Content Hook Factory static app,
   - public URL / release proof,
   - content sample ingestion,
   - QA PASS/BLOCKED verdict,
   - one sellable 199-399 EUR content sprint package,
   - first paid content sprint proof.
6. Any agent proposing a new product must state what current P0 proof it would delay.
7. A task is not progress unless it reduces distance to working app, export proof, content asset proof, deploy proof or paid sprint proof.

## Kill criteria for distractions

Reject or backlog anything that does not answer one of these questions:

- Does it help generate better hooks?
- Does it help create sellable posts/video scripts/landing blocks?
- Does it help turn content examples into reusable patterns?
- Does it help sell a 199-399 EUR content sprint?
- Does it help verify deploy/QA/revenue proof?

If the answer is no, it is not active P0 work.
