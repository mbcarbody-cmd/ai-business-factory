# Agent Council Orchestrator

This folder defines how agents must work together.

## Purpose

The system must not act like one chat answer. It must act like a small company.

## Council roles

- CEO Strategist
- Market Analyst
- Product Architect
- Builder
- QA Critic
- SEO Growth
- Sales Operator
- Delivery Manager
- CFO
- Work Auditor

## Required council cycle

1. CEO states the priority.
2. Market Analyst gives market and competitor findings.
3. Product Architect converts findings into product structure.
4. Builder creates or changes real repo files.
5. QA Critic checks if the output is weak or unfinished.
6. SEO Growth improves wording, landing and content direction.
7. Sales Operator prepares targets and messages.
8. Delivery Manager prepares delivery plan.
9. CFO checks cost, effort and pricing logic.
10. Work Auditor writes what changed and next action.

## Communication rule

Every agent must answer with:

- observation
- decision
- tasks for other agents
- own next output
- blockers

## Main focus

The main system is Parts Business OS.

It includes:

- work accounting
- part ID flow
- task tracking
- labels
- photo workflow
- listing intelligence
- SEO and content intelligence
- sales and delivery support

## Anti-random rule

No disconnected new product is allowed unless CEO Strategist changes the priority and Work Auditor approves the reason.
