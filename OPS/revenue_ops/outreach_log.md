# Outreach Log

Owner: CRO-2 Outbound Conversion Director

## Purpose

Track what message was sent, to whom, and what happened after.

## Log format

| Date | Lead ID | Segment | Message angle | CTA | Channel | Result | Next action |
|---|---|---|---|---|---|---|---|

## Message test rules

- One message = one pain + one concrete offer + one simple CTA.
- No vague AI hype.
- No long agency-style pitch.
- Every segment needs a different reason to care.
- Reply data must update `OPS/revenue_ops/lead_pipeline.json`.

## Current message angles to test

1. 72h automation pilot for small business admin chaos.
2. Lead intake + outreach generator for local service businesses.
3. Inventory/listing workflow automation for used parts sellers.
4. Simple AI assistant setup with monthly maintenance.
