# Evaluation Rules

This file prevents weak scattered work.

## Before build

Any task must define:

- user
- problem
- demo path
- package value
- delivery path
- next action

## Score

Use 0 to 5 for each:

- user clarity
- problem strength
- demo speed
- simple wording
- advantage
- delivery simplicity
- next action

## Decision

- high score: build
- medium score: refine
- low score: park

## Current focus

Main focus is Parts Workforce OS.

Supporting modules:

- work accounting
- part ID flow
- label flow
- photo flow
- listing and SEO intelligence
- sales and delivery support

## Rule

No new disconnected direction until the main system has a working demo, public page, target list, contact pack and delivery plan.
