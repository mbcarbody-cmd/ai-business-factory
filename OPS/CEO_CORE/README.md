# CEO Core

This folder defines how the repo works.

## Main rule

Build one strong working system before starting new random ideas.

## Priority

1. Parts Workforce OS
2. SEO and content intelligence for the same system
3. Sales and delivery support for the same system

## Before any new build

Write these answers:

- user
- problem
- current alternatives
- better offer
- smallest demo
- next task

## Work cycle

1. Research what users search for.
2. Find what competitors promise.
3. Improve the main product.
4. Add or fix one working feature.
5. Write the output path in the work log.
6. Define next action.

## Reject work when

- it is only an idea
- it creates a separate direction
- it has no user
- it has no demo
- it does not improve the priority system

## Done means

A task is done only when a real file exists in the repo and the next action is written.
