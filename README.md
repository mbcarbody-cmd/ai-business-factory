# AI Business Factory

Product workspace for building small business automation tools.

## Current product

**AI Agent Setup**

A done-for-you business automation setup for small companies:

- landing page and lead capture
- lead intake dashboard
- outreach message generator
- lead score calculator
- shipping, listing and ads workflow modules
- delivery SOP
- client handoff text
