# Market Pulse PWA

Status: working static PWA prototype
Date: 2026-06-14

## What it is

Mobile-first market watchlist and decision journal MVP.

It helps a user:

- create a watchlist,
- store a plan per asset,
- run a manual risk/signal checklist,
- score decision discipline,
- write a decision journal,
- understand monetization path.

## What it is not

It is not a broker.
It does not execute trades.
It does not provide final financial advice.
It does not use live market data yet.

## Run locally

Open `index.html` in a browser or host it as a static site.

## Android route

1. Host static demo.
2. Test on Android browser.
3. Wrap via Capacitor or Trusted Web Activity.
4. Add icons/splash.
5. Only then consider Play Store.

## Monetization hypothesis

- free decision journal,
- premium alerts/templates/export,
