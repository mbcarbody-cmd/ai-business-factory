Updated: 2026-06-15  
Owner: PF10X-01-W01 Boilerplate Captain  
Status: active

## Purpose

This template prevents every product from starting from zero. It is the minimum shell required to present Parts Seller OS as a paid pilot offer.

## Included sections

- Hero and offer promise.
- Buyer pain and contrast.
- 72h paid pilot package.
- Workflow demo blocks.
- Pricing / payment placeholder.
- Lead capture form placeholder.
- QA and CFO proof placeholders.
- Next action CTA.

## Usage

1. Copy this folder into a new product or campaign folder.
2. Replace placeholder company/demo text with the target seller segment.
3. Attach payment link or invoice instructions.
4. Run QA conversion scorecard.
5. Deploy or create NO URL blocker.
6. Route to Revenue Ops for exact leads.

## Done rule

The template is not considered production-ready until it has:

- public URL or NO URL blocker;
- working lead capture or manual contact CTA;
- payment path or invoice draft;
- QA scorecard;
- CFO verdict;
- outreach pack.
