# Auto Parts Title Generator PWA

Status: working static PWA prototype
Date: 2026-06-14

## What it does

A mobile-first mini app for used auto parts sellers.

It generates better listing titles from:

- part name,
- OEM/code,
- vehicle model,
- side/position,
- condition,
- language.

It also returns a simple QA verdict:

- READY when title has enough data,
- BLOCK / needs data when critical fields are missing.

## Why this product matters

Bad listing titles reduce search visibility and buyer trust. This mini tool is small enough to ship fast and useful enough to become part of Parts Seller OS.

## Run locally

Open `index.html` in a browser or host it as a static site.
