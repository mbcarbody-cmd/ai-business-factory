# Date Spark PWA

Status: working static PWA prototype
Date: 2026-06-14

## What it is

Mobile-first dating/social utility MVP.

It is not a full dating network yet. It is a fast product prototype that helps a user:

- enter profile info,
- generate a better dating bio,
- compare against sample profiles,
- get compatibility score,
- generate icebreakers,
- generate date ideas,
- see basic safety rules,
- understand monetization path.

## Why this route

A full dating app needs accounts, backend, chat, moderation, report/block, privacy and user acquisition. That cannot be honestly shipped as a safe real product in two days.

A useful dating-adjacent micro product can ship fast and validate demand:

- profile optimizer,
- icebreaker pack,
- date idea generator,
- local event/date planner,
- private waitlist/community MVP.

## Run locally

Open `index.html` in a browser or host it as a static site.

## Android route

1. Host static demo.
2. Test on Android browser.
3. Wrap via Capacitor or Trusted Web Activity.
4. Add icons/splash.
5. Only then consider Play Store.

## Monetization hypothesis

Start with profile/icebreaker/date-idea utility before building a full dating network:

- free basic profile optimizer,
- 3-9 EUR premium pack,
- local date ideas / event affiliate,
- profile audit service.
