# Parts Seller OS Component Library

Updated: 2026-06-15  
Owner: PF10X-04-W01 Component Library Captain  
Status: active

## Component 1 — Hero offer

Purpose: introduce the product and CTA.

Fields:
- badge: 72h paid pilot
- headline: One workflow for part intake, storage, pricing and listing readiness
- subheadline: Dashboard for used auto parts sellers
- primary CTA: Request pilot
- secondary CTA: See workflow

## Component 2 — Buyer pain contrast

Purpose: show the difference between manual workflow and operating dashboard.

Rows:
- category decision -> suggested category and confidence
- shelf/storage decision -> storage profile and location logic
- price decision -> price, floor and confidence
- listing readiness -> ready, needs photo, needs price, pending location or hold

## Component 3 — Pricing card

Purpose: make the paid pilot easy to understand.

Fields:
- pilot setup: 300-900 EUR
- pilot delivery: 72 hours after sample data
- sample size: 20-100 parts
- monthly target after pilot: 99-299 EUR
- payment path: Stripe, PayPal, Revolut Business or invoice

## Component 4 — Workflow cards

Purpose: explain the product workflow quickly.

Cards:
1. Add part
2. Map category
3. Suggest storage
4. Calculate price
5. Set listing status
6. Export or reserve

## Component 5 — Lead capture block

Purpose: capture seller interest.

Fields:
- company name
- contact email or WhatsApp
- current part count
- current marketplaces
- biggest workflow issue

## Component 6 — Proof strip

Purpose: show operating trust.

Proof fields:
- QA scorecard status
- CFO verdict
- payment path status
- deploy proof
- revenue pipeline status

## Component 7 — Short outreach opener

Purpose: give Revenue Ops a reusable opener.

Subject pattern: 72h pilot for used parts intake, pricing and listing readiness

Body pattern: concise note explaining the one-seller dashboard, sample data pilot and request for a short reply.

## Done rule

This component library is done for the first production cycle when at least three components are used inside a landing or demo page and QA confirms the CTA and offer are clear.
